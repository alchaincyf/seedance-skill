# Seedance 提示词规范

全部来自字节 Seed 官方发布博客与官方演示物料。**这是模型团队自己写的 prompt，配着对应成片**，不是二手转述。

## 官方范式（Seedance 没有强制公式，但所有官方样本都是这个结构）

```
[时长]，[画幅]，[一句话场景定位]。
[参考素材分组绑定]
[全局约束：音轨 / 风格 / 禁止项]

[时间戳段落 1]：[镜头怎么动] + [主体做什么]
[时间戳段落 2]：[镜头怎么动] + [主体做什么]
...
```

四件事缺一不可：**时长画幅 → 参考绑定 → 镜头序列 → 全局约束**。

## 引用语法（官方原文用法）

| 写法 | 用途 |
|---|---|
| `@图片1` / `@Image 1` | 图片参考，上限 30 张 |
| `@视频1` / `@Video 1` | 视频参考，上限 10 段 |
| `@白模1` / `@Clay Render 1` | 白模渲染参考，属于视频参考 |
| 音频 | 上限 10 段，写法为「声音参考音频1」 |

单次总上限 **30 图 + 10 视频 + 10 音频 = 50**。

## 定向引用：本规范的核心

**每个参考素材必须写清三件事**，缺第三件会翻车：

1. **它是什么角色** —— 时间轴参考？造型参考？音色参考？
2. **继承什么** —— 逐项列出
3. **明确不继承什么** —— 身份、造型、光线、色彩、环境、声音、故事背景

官方白模案例的拆法（最标准的范本）：

> 参考 @白模1 的**运镜、镜头节奏、景别变化、主体轨迹和镜头调度**。参考 @图片2 的**角色外形、场景、材质、光照、色彩和童话氛围**，将白模渲染为梦幻温暖、儿童幻想感、3D 动画短片。

注意它把「结构」和「质感」完全分开：**运动信息从白模来，视觉信息从图片来**。

反向的负面声明（影视飓风实测版，比官方更狠）：

> 不从该参考继承人物身份、船体造型、光线、色彩、海面状态、故事背景或声音。

## 时间戳

官方格式就是最朴素的 `0-5s:` / `6-10s:` / `11-20s:`。

**每一段里必须同时交代两件事：镜头怎么动 + 主体做什么。** 只写一样，模型会自由发挥另一样。

官方京剧案例（时间戳 + 参考绑定同时用的范本）：

> 16:9 宽银幕，电影质感，单一连续镜头，运镜平滑，无剪切。场景参考：@图片4。
> **0–5秒**：以 @图片2 中的霸王特写开场。镜头缓慢环绕他的上半身并过渡为中景。霸王旋身转向，身形与背后靠旗快速扫过镜头形成自然遮挡，镜头顺势跟到 @图片1 中虞姬一侧。
> **6–10秒**：镜头以中景平稳环绕虞姬（@图片1），跟随她的水袖划过弧线。她抬臂、抖腕、甩开水袖、半转身，随后收袖定势，侧目望向霸王。
> **11–20秒**：@图片3 中的男性武生以空翻入场。……镜头从武生的中近景缓缓后拉至全舞台视角。结尾三人面向观众，同步亮相定势。

## 负面约束：具体到「排除哪个错误品类」

官方从不写「不要低质量」。实际写法：

| 官方原句 | 排除的是 |
|---|---|
| 避免白模塑料感 | 材质错误 |
| 不做教学拆解 / 不出现维修说明式镜头 | 叙事品类错误 |
| 无箭头标签 | 图形元素错误 |
| 不得突然消失 | 物理连续性错误 |
| 无字幕、无音乐 / 无BGM | 音轨错误 |

## 音频

三件事分开写：

- **对白**：直接嵌在镜头描述里，用引号。例：`他说："So the selling point is An-ti-Swallow?"`
- **音色**：与人物成对绑定。例：`人物参考图8，声音参考音频1`。同一人再出场写 `继续参考图8和音频1`
- **环境声与配乐**：先排除再指定。例：`无BGM，保留会议室环境声和真实对白`

**声音的变化也要写**。官方延长案例：`声音从雨打玻璃转为隔窗闷雨、房间声与呼吸`。

# 三个可套用模板

## 模板一 · 多素材参考（素材 ≥ 10 时用）

素材多到十几张时，**按功能分组打包，只有人物才逐个点名**。这是唯一不会写崩的组织方式。

```
[时长]，[画幅]，[一句话场景定位]。
环境参考图A、图B；全景座次参考图C、图D；桌面道具参考图E、图F、图G；
角色1参考图H，声音参考音频1；角色2参考图I，声音参考音频2。
[全局音轨约束]

开场[机位+运镜]，[画面内容]，[一个词的气氛]。
切[景别]，[角色]，人物参考图H，声音参考音频1，他说："[台词]"
切[景别]，[角色]，人物参考图I，声音参考音频2，他说："[台词]"
切回[景别]，继续参考图H和音频1，他说："[台词]"
最后[机位关系，如「从X肩侧拍向Y」]，[前景参考图H，主体参考图I]，[台词]
```

官方原样本是一段 18 图 + 3 音频的会议室对白戏，出自 Seedance 2.5 官方发布物料。

## 模板二 · 白模驱动（结构与质感分离）

```
以 @白模1 为动作骨架，成片严格保持[N]秒。
参考 @白模1 的：运镜、镜头节奏、景别变化、主体轨迹、镜头调度；
不从 @白模1 继承：材质、光线、色彩、身份、故事背景、声音。

参考 @图片1 的：材质质感、光比、色温、景深关系、[具体到该场景的视觉元素]；
不从 @图片1 继承：构图、机位、物件的画面位置。

0-Xs：[镜头怎么动] + [主体做什么]
X-Ys：[镜头怎么动] + [主体做什么]

[整体风格锚点：真实片名 + 器材规格]。
避免[材质错误]，不做[叙事品类错误]，不出现[图形元素错误]。
```

## 模板三 · 多轮延长

```
向后延长视频[N]，承接[当前末帧 / 上一段末帧]的[画面内容]。
[镜头怎么继续动]，[主体的连续动作]。
[需要保持连续的物理细节]，不得突然消失。
声音从[前一段的声音]转为[这一段的声音]。
全程无切镜。
```

官方原样本是「雨天城市穿窗入卧室」的两段接力，出自 Seedance 2.5 官方发布物料。
