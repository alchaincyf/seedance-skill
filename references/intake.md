# 需求澄清：从一句话到可执行参数

用户来的时候通常只有一句话：「我想要一个雨夜追车的镜头」。

这句话里缺的东西，**每一样都会在某个环节把活儿卡住**：不知道时长就定不了帧数，不知道画幅就没法判断主体会不会出画，不知道要不要切镜就不知道白模是一段还是几段。但反过来，把二十个问题一次砸给用户，他会跑掉。

所以规矩是：**能从他的话里推断的就推断，把推断结果摊出来让他否决；只有推断不出来、而且不同答案会导出完全不同产出的，才真的问。**

## 三个必须问的（其余都能先替他定）

| 问题 | 为什么它不能替他猜 | 落到哪 |
|---|---|---|
| **成片多长** | 时长决定了这条片子能装几个镜头、每个镜头有多少呼吸空间，也直接决定这次生成花多少钱 | `meta.duration` |
| **发在哪** （→ 画幅） | 16:9 和 9:16 不是裁一刀的事，构图、机位高度、主体占比全都要重算 | `meta.aspect` |
| **一镜到底还是切镜头** | 这是白模结构的分水岭：一个 shot 还是多个 shot | `shots` 的个数 |

第三问如果用户答不上来（很常见，他没想过），就用这条经验帮他定：

> **爽点如果在「空间连续」——穿过、跟着、绕着、一路推进——就一镜到底；爽点如果在「关系对撞」——他看她、正反打、同一件事的三个角度——就切镜头。**

## 其余的先替他填，一次性摊出来让他否决

下面这张表是「我按这个理解开工，不对你说」。给用户看填好的表，比问他十个问题快得多，也准得多——**他看得懂具体的东西，看不懂抽象的问题**。

| 维度 | 默认怎么定 | 落到哪 |
|---|---|---|
| 摄影机类型 | 从他的形容词反推：紧张/慌乱→手持；跟着走→斯坦尼康；庄重/仪式感→三脚架或摇臂；开阔/俯瞰→航拍；第一人称→主观 | `shots[].rig` + `shake` |
| 跟随方式 | 主体朝镜头走→前置倒退（`lead`）；跟着主体走→背后跟随（`follow`）；主体是被观察对象→固定或环绕 | `rig` |
| 焦段 | 室内、要纵深、要压迫感→24-28mm；常规叙事→35mm；人物情绪→50-85mm | `shots[].lens` |
| 景别 | 由机位距离算出来，不单独填。想要什么景别就调距离（见 `camera-rig.md` 的景别距离表） | `lens` + 距离 |
| 主体数量 | 默认 1 个主角。**超过 3 个互动主体要提醒他风险**：四家模型官方口径一致，多主体互动稳定性仍是弱项 | `subjects` |
| 风格锚点 | 从他提到的片名、年代、天气推。他没提就问一句，这个不能编 | prompt 的画质段 |
| 音频 | 默认「有环境声、无配乐」。有对白必须单独确认台词原文 | prompt 的音效段 |
| 参考素材 | 他给了照片→走产线 D 反解；没给→产线 C 生成参考图 | `@图片N` |

## 时长与镜头数的实证边界

时长这一格填错，后面全白干，所以单独列出来：

| 事实 | 出处 |
|---|---|
| Seedance 2.5 单段上限 **30 秒**，输出 **720P** | 2026-08-06 实测（输入 30 直接接受） |
| **15 秒可用**，手动模式数字框直接输 15 | 2026-08-16 实测 |
| 成片 **24fps**，白模 30fps，**跨帧率切点仍然对得上**（误差 < 1 帧） | 2026-08-16 逐帧核对：白模切点 3.967/8.467/11.967s → 成片 3.958/8.458/12.000s |
| 60 秒要两段拼，或走多轮延长 | 单段上限决定 |

镜头数按这个给：

- **一个镜头低于 2.5 秒站不住**。AI 来不及建立空间关系，观众也来不及读懂
- 12 秒 → 1-4 个镜头；15 秒 → 1-5 个；30 秒 → 3-8 个
- 切点要卡在**动作转折处**，不是均匀分。均匀切出来是 PPT 翻页

## 摊完假设之后，先给他看的不是白模

顺序很重要：**先给 3-5 行的镜头表（时间/景别/运镜/主体在干嘛），让他改；改完才建 scene.json。**

镜头表是文字，改一行只要一秒；白模建完再改，那是几分钟。2026-08-15 那次三条片子全部返工——一条要重排全部人物轨迹、一条要做时间重映射、一条只能拿去本地重剪——全部是因为跳过了这一步，直接照着自己的理解建了白模。

镜头表长这样，用户能直接在上面划：

```
0-4s    中景  背后跟随，广角，与他保持 4 米      他快步走进巷子，帽檐滴水
4-7.5s  中近景 硬切到前方倒退跟拍                  他抬头，脚步没停
7.5-10s 中景→中近景 绕到他左侧环绕 135 度          他停下，回头看身后
10-12s  全景→大远景 起吊拉升到 15 米俯瞰            他继续往深处走，整条巷子显形
```

## 用户说「你看着办」的时候

那就真的看着办，别再追问——但要在交付时把你替他做的每个决定单列一行，方便他事后否决。**替他决定不是问题，替他决定但不说才是。**

## 一句话需求 → 完整参数，一个真实例子

用户说：「拍一个人在雨夜的小巷里往深处走，最后镜头升起来把整条巷子露出来，15 秒竖屏。」

能直接推断的：
- 时长 15 秒 ✅ 他说了
- 画幅 9:16 ✅ 他说了（竖屏）
- 结尾要「升起来把整条巷子露出来」→ 末段是 `crane`，且必须切镜或者一镜到底走完全程
- 「往深处走」→ 主体背对镜头 → 前段是 `follow`
- 「雨夜小巷」→ 室内感的窄空间 → 广角 24-28mm；低照度 → 提醒他参考图要给足光比

真正要问的只剩一个：**中间那八秒他想要什么**。一镜到底从跟随平滑摇到升起，还是中间切一刀给个正面？这个不能替他定——前者是氛围片，后者是叙事片，成片完全是两个东西。

问一句，比问十句准。
