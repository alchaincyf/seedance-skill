# 参考图六要素配方

2026-08-06 实测得出。同一场景，形容词版出的是图库壁纸，技术术语版直接变成电影画面。

## 为什么形容词没用

「电影感实拍质感」「胶片颗粒」这类词，模型只能理解成「好看」。出来的是：

- **图库壁纸**：均匀日落曝光、没有主体、没有戏剧性布光
- **产品静物**：柔光箱打的广告图，写了「巨大」但画面里一点都不大

**用这种图去当 Seedance 的参考，反而会把视频质量往下拉。**

原理：2026 年的视频/图像模型是在海量专业摄影数据上训练的，**它们对技术术语的响应远好于华丽形容词**。

## 六要素（缺一件就掉档）

| # | 要素 | 反例 → 正例 |
|---|---|---|
| 1 | **真实片名锚点** | 「电影感」→《敦刻尔克》《壮志凌云独行侠》《银翼杀手2049》《沙丘》《降临》 |
| 2 | **器材规格** | 「高清」→ IMAX 65mm、Kodak Vision3 |
| 3 | **大气介质** | 「光线好」→ 体积光柱、丁达尔光锥、大气透视、悬浮尘埃。**空气必须是可见的**，这是大片感的核心 |
| 4 | **尺度参照物** | 「巨大的书」→ 书旁站一个渺小人影；「云谷」→ 云壁边一架战斗机小剪影 |
| 5 | **戏剧性布光** | 「自然光」→ 低角度侧逆光、大光比、轮廓光。图库照片是均匀曝光，电影不是 |
| 6 | **实拍瑕疵** | 「干净」→ 划痕、油渍、锈迹、镜头眩光、轻微暗角、高光柔和滚降 |

## 两条避坑（实测踩出来的）

🔴 **不要写「变形宽银幕」/「anamorphic」**
模型会把宽银幕的**信箱式黑边和胶片框一起画进画面**。参考图带边框，Seedance 会连边框一起继承。

🔴 **必须明写「实拍照片质感不是CG渲染不是概念插画」**
否则出来的是概念艺术图——漂亮但假，而且色调容易塌成单一冷蓝。

## 固定尾巴（每张都加）

> 实拍照片质感不是CG渲染不是概念插画，Kodak Vision3 胶片颗粒，高动态范围，暗部深沉保留细节，高光柔和滚降不过曝。画面内容完整填满整个16:9画幅，不要黑边，不要信箱式黑框，不要边框装饰

## 出图后统一裁边

即便写了「不要边框」，仍可能残留一圈细描边。统一裁掉四周 36px：

```bash
ffmpeg -y -i X.png -vf "crop=iw-72:ih-72:36:36,scale=2560:1440" X-已裁边.png
```

## 生成命令

用哪个文生图后端都行，配方与后端无关。

⚠️ **尺寸别省**：16:9 出 **2560×1440**。部分后端对高分辨率档位有像素数门槛（实测过一个是 3,686,400 像素，2560×1440 恰好达标）；更要紧的是参考图分辨率不够会把成片质感一起拉下来。

## 一个完整范例

```
IMAX 65mm 实景摄影，参照《银翼杀手2049》的体积光与《降临》的巨物尺度。
一本高达数十米的巨型精装书立在开阔的水泥地面上，书页正在缓缓翻动，
纸张的纤维、折痕和印刷字迹在强烈侧逆光下清晰可见。
画面下方站着一个极其渺小的人影背影，与书形成悬殊尺度对比。
空气中悬浮着被光照亮的纸屑和尘埃形成丁达尔光柱。
暖金色主光从左后方来，环境是冷调，形成暖冷对比不要只有单一蓝色。
实拍照片质感不是CG渲染不是概念插画，真实的纸张材质与水泥地面质感，
Kodak Vision3 胶片颗粒，暗部深沉保留细节，高光柔和滚降，轻微暗角。
画面内容完整填满整个16:9画幅，不要黑边不要边框
```

拆开看：片名锚点（银翼杀手2049 + 降临）、器材（IMAX 65mm、Kodak Vision3）、大气介质（丁达尔光柱、纸屑尘埃）、尺度参照（渺小人影背影）、戏剧布光（强烈侧逆光 + 暖金主光 + 冷调环境）、实拍瑕疵（暗角、高光滚降）—— 六件齐了。

## 参考图挂给 Seedance 时

参考图的职责是**锁材质与光线**，不是锁构图。所以定向声明应该写：

```
参考 @图片N 的：材质质感、光比、色温、景深关系；
不从 @图片N 继承：构图、机位和任何物件的画面位置。
```

**构图和机位交给白模管**（见 `whitemodel.md`）。十几张参考图如果各自都带构图倾向，会把镜头拽向十几个方向。
